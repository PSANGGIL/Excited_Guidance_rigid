평가의 우선 목표는 화학적으로 합리적인 다양한 구조를 생성하는 능력이다.
XTB/sTDA는 조건에 따른 물성 이동을 보는 보조 평가이며, 해당 계산의 목표

3. 구조 파손 A: heavy bond order와 H 상태의 충돌

전체 1,000개 endpoint의 36,413개 실제 heavy atom을 검사했다.
각 원자에서 B_i = sum_j bond_order(i,j), H_i = 예측 H count로 정의하고,
원래 상태와 H_i=0인 상태를 RDKit 원자가 검사에 각각 넣었다.

- 무효 426개 중 312개(73.24%)는 수소를 제거해도 heavy bond-order 합이
  허용 원자가를 넘는다. 이 경우 수소 후처리만으로 해결할 수 없다.
- 나머지 114개는 H를 줄이면 모든 국소 overflow를 제거할 수 있다.
- 원자가 초과 원자 933개, 그중 H=0에서도 초과하는 원자 500개.
- 주요 패턴: C(charge 0, H 0, B 5) 450개;
  C(charge 0, H 1, B 4) 423개. 이는 분자 수가 아닌 원자 수다.
- heavy-only overflow 중성 C 464개 중 463개는 heavy 이웃이 4개 이하다.
  따라서 연결 이웃 수를 4로 제한하는 규칙만으로 문제를 막을 수 없다.

실제 사례(모든 index는 0-based):
- 생성 #000006: 요청 40 / 실제 41 heavy atoms.
  atom index 38, original slot 40은 C, H=0, heavy degree=4,
  heavy bond order=5이다. 수소가 추가되기 전부터 과원자가다.
- 생성 #000007: 요청 40 / 실제 42 heavy atoms.
  atom index 14, original slot 15는 C, H=1, heavy degree=3,
  heavy bond order=4이다. H 상태와 결합차수 합이 충돌한다.
  여기서는 H를 하나 줄이는 진단용 변경으로 연결된 중성·폐각이 된다.
  이것만으로 H가 원래 틀렸는지, bond order가 틀렸는지는 확정하지 못한다.

고정 heavy graph/원소/전하에서 train-supported H만 재할당한 반사실 진단:
- 무효 426개 중 H assignment 존재 및 RDKit valid 111개.
- 그중 연결된 중성·폐각 106개.
- 원래 유효하지만 radical이 있던 102개 중 90개도 같은 진단에서
  연결된 중성·폐각이 되었다.
원본을 바꾸거나 새 XTB를 수행한 결과가 아니다. 이 숫자를 실제 생성
성공률에 더하지 않는다. 올바른 구조가 복원됐다는 증명도 아니다.

판정: H count를 모델에 넣은 것만으로 H/bond 공동 일관성이 보장되지 않는다.
평균적인 auxiliary loss 감소와 개별 sampled endpoint의 유효성은 구분해야 한다.

4. 구조 파손 B: 최종 projection의 feasible 선택지 소실

저장된 optional joint/MAP 결과: optimal 93, infeasible 907.
raw 무효에서 11개를 복구했지만 raw 유효 492개도 projection에서 실패했다.
원본과 동일한 그래프는 53개이다. raw 결과는 별도로 보존돼 있다.

확인한 필요조건 위반:
- 양의 확률 support에서 가능한 real atom count 범위에 요청 count가
  없는 경우 679개.
- 원자별 가능한 bond-order/valence 범위가 충돌하는 경우 179개.
- 두 조건의 합집합 730개: infeasible 907개의 80.49%를 설명한다.
  나머지 실패의 원인은 모두 분리해 규명한 상태가 아니다.

예: #000003은 요청 count 32지만 support 내 real atom 수가 29로 고정된다.
#000005는 요청 32지만 가능한 count가 40이다. 시간제한 연장만으로 이러한
논리적 불가능 조건을 해결할 수 없다.

실제 categorical temperature는 T=0.05이다. CFG=1의 corrected probability
경로는 허용 class에 대해 q_k ∝ max(p_k, 1e−9)^(1/T), 즉 지수 20을 적용한다.
p=[0.999,0.001]의 작은 후보는 float64에서 약 1.02e−60이지만 float32
계산에서는 0으로 내려간다. 의도적인 unsupported class mask와 이 수치적 0을
같은 것으로 취급하면 안 된다.

저장된 실제 heavy-heavy 결합 42,688개 중 41,059개(96.18%)는 양의 확률을
가진 bond class가 하나뿐이다. NONE pair가 많아서 생긴 집계 효과를 줄이기
위해 실제 결합만 따로 계산한 수치다.
실제 atom 36,413개 중 85.26%도 양의 확률 state가 하나뿐이다.
solver는 p>0인 선택지만 변수로 만들므로 underflow가 feasible set을 바꾼다.
모든 0이 underflow라는 주장이나 raw 실패 전체가 temperature 때문이라는
인과 주장은 하지 않는다. temperature 적용 전 logits가 없어 저장된 0에서
원래 작은 확률을 역으로 복원할 수도 없다.

현재 코드 위치:
- molguidance/models/ctmc_vector_field.py:36  기본 temperature
- molguidance/models/classifier_free_guidance.py:76  guided probability
- molguidance/models/classifier_free_guidance.py:596  required count 전달
- molguidance/models/classifier_free_guidance.py:985  endpoint 확률 저장
- molguidance/analysis/joint_decode.py:152  p>0 support 선택

위 경로는 이 스냅샷에 그대로 남아 있다. 이번 커밋은 기록이며 수정을
완료했다는 선언이 아니다.

일관되게 남는다. count kernel 가중치는 모델 복사 확률이 아니다.

각 edge를 제거한 최단 경로+1로 가장 짧은 cycle 길이도 확인했다.
7원 이상이 필요한 edge가 있는 분자는 생성 232/452, train 66/1264이다.

452개 모두 HP1KG 전체 DB와 canonical non-stereo graph 중복이 없고,

서로 다른 부적절한 그래프가 많이 나와도 uniqueness는 높아질 수 있다.

6. 좌표 평가와 재분석에서 정정한 항목

XTB 최적화 전후 heavy-atom aligned RMSD 평균 0.745 Å, 중앙값 0.617 Å.
1 Å를 넘는 분자는 126/452개다. 이는 좌표 변화량이며 strain energy 자체가 아니다.
기존 heavy bond WBO<0.3 경고 1개, 새 heavy contact WBO>0.5 경고 18개,
H transfer 경고 0개. 합집합 WBO 경고는 18개다.
WBO 경고는 결합 재편성 검토 신호이며 완전한 molecular identity 판정이 아니다.

기존 strict_generation.py:50 및 초기 분석 helper는 ring의 원자가 모두
aromatic이면 평면성 검사에 포함했다. 그러면 비방향족 연결 결합을 가진
cycle도 포함될 수 있다. 2026-10-29 재분석에서는 고리 전체 결합이 aromatic인
경우로 정의를 좁혔다. 이 역시 RDKit에 기반한 운영상 지표다.

- 최적화 후 plane RMS>0.15 Å: 기존 102개 → 새 기준 89개.
- 계산 완료분의 입력 geometry 통과: 기존 364개 → 새 기준 373개.
- 이는 평가 정의 변경이며 모델 개선이나 새 생성 성공이 아니다.
- production strict_generation.py의 기존 평면성 로직은 아직 수정하지 않았다.
  현재 callback의 geometry 수치와 재분석 수치를 같은 정의로 합치지 않는다.

구조별 오기 정정:
- #830에 O−O 결합이 있다는 이전 설명은 오류다. 원본 SDF에서 O는 C와

- #189의 [N+](=O)[O−]는 nitro 표기이다. net charge 0, radical 0이다.

8. XTB/sTDA를 보조 지표로 해석하는 기준

계산 완료 452개의 Q 평균 −1.081 ± 0.880 eV, 목표 MAE 1.124 eV.
|Q|≤0.1인 후보 34개는 전체 생성의 3.4%, 계산 완료분의 7.52%다.
근접 후보 중 S1<1 eV가 17개다. Q 하나의 조건은 S1/T1 개별 절대값이나
oscillator strength를 고정하지 않는다.

학습 label은 NEVPT2, 후처리는 XTB/sTDA이다. 과거 DB 기준 Q≈0인 11개는
XTB에서 평균 −0.531 eV였으며 1개만 같은 ±0.1 eV 구간에 남았다.
과거 DB 계산과 현재 생성 계산은 초기 geometry protocol도 다르다.
전체 평균 offset을 빼서 생성물의 정답 Q를 추정하지 않았다.

이번 단일 조건·seed 표본에는 matched CFG=0/다른 조건 대조가 없다.
원자 수 sampler, 구조 생존 편향, 계산 수준 차이가 섞여 있으므로 물성 이동을
가이던스만의 인과효과로 해석하지 않는다. 고수준 전자구조·Hessian·합성
가능성 검증도 시행한 상태가 아니다.

9. 다음 수정 및 평가의 우선순위 — 아직 적용하지 않은 제안

A. 평가 계약을 먼저 분리한다.
   raw graph validity, connected/closed-shell, 좌표 진단, 구조 다양성,
   XTB 완료, condition fidelity를 별도 분모로 기록한다.
   3·4원 또는 7원 이상이라는 이유만으로 모든 후보를 강제 제외하지 않는다.
   production/reanalysis의 aromatic-plane 정의와 정정 사항을 일치시킨다.

B. 기존 checkpoint에서 final decoder의 수치 support/count 문제를 대조한다.
   temperature 적용 전 log-probability 또는 logits와 의도적 class mask를
   별도 저장하고 log-domain 비용을 사용한다. exp 후 p==0을 금지 조건으로
   쓰지 않는다. 의도적으로 금지한 class를 epsilon으로 되살리지 않는다.
   stochastic fake/real count와 strict requested count의 의미를 통일하거나,
   actual count 유지와 requested count 강제를 서로 다른 실험으로 기록한다.
   동일 checkpoint/count/noise로 raw와 projected 성능·수정량·다양성을 비교한다.

C. H/atom-state와 bond-order 공동 일관성을 개선한다.
   degree cap과 H-only 후처리의 한계를 반영해 원자별 valence 분포와 실제
   sampled endpoint의 충돌을 직접 측정한다. 전역 Kekulé assignment 및
   connectivity와의 상호작용을 검증한다. loss 항 추가만으로 해결을 선언하지 않는다.

D. 구조 기준을 통과한 집단에서 다양성을 평가한다.
   scaffold와 ring-system별 빈도/집중도, pairwise fingerprint 분포,
   치환기 수·위치, hetero atom 위치·조성, non-ring atom 비율을 기록한다.
   원자 수·조건 구간별 비교를 유지하고 novel graph 수만으로 순위를 정하지 않는다.
   DB 지원이 낮은 구조는 novelty와 불합리성을 구분해 개별 검토한다.

E. 위 결과가 확인된 뒤 학습 objective 변경 여부를 결정한다.
   원자 수·temperature·projection의 평가 정의가 다른 실험을 학습 효과로
   섞지 않는다. XTB 목표 오차를 낮추는 것만으로 새로운 모델을 선택하지 않는다.
   aromatic loss weight 증가, 모든 큰 고리 금지, 장기학습 연장만으로
   문제가 해결된다는 근거는 현재 없다.
