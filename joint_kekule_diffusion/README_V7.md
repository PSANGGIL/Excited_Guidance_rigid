# Joint-edge molecular diffusion v7

V7 is an isolated implementation path. It does not overwrite the v5/v6 model
or checkpoints.

## State and diffusion

The categorical edge variable is one seven-class state:

| id | state |
|---:|---|
| 0 | no edge |
| 1 | regular single |
| 2 | regular double |
| 3 | regular triple |
| 4 | aromatic-perceived edge with Kekule single order |
| 5 | aromatic-perceived edge with Kekule double order |
| 6 | aromatic-perceived edge with Kekule triple order |

The last class is required for four aromatic-triple edges in the CECPAD record.
It is not equivalent to forcing every aromatic perimeter edge to use the RDKit
aromatic bond class. The model predicts this joint state with one D3PM kernel
and one output head. Existence, bond-order and aromatic probabilities used by
auxiliary losses are exact marginal views of the same joint distribution.

Atom state remains the joint heavy-atom tuple (element, formal charge, total
valence, aromatic role). Hydrogen is the residual implied by this state and
the final bond-order graph; it is not an independently diffused node.

Coordinates use a centered Gaussian DDPM. The coordinate score is built from
relative vectors, and the validation gate measures translation invariance,
permutation equivariance and rotation equivariance.

## Reverse process and projection

The 500-step reverse process applies only the learned D3PM posterior and
Cartesian DDPM update. There is no aromatic-cycle, valence, connectivity,
support or topology projection at an intermediate timestep.

After the final reverse step, a joint MILP chooses atom states and seven-class
edges together. Its hard constraints include:

- exactly one state per atom and at most one class per candidate edge;
- net formal charge;
- state-dependent valence and implicit-hydrogen bounds;
- aromatic endpoint roles and aromatic degree;
- connectedness through single-commodity flow;
- RDKit sanitization and aromatic-role agreement.

A train-only, atom-count-conditional joint topology sample supplies a soft
cycle-rank target. Because connected-graph cycle rank is `E - V + 1`, its
absolute edge-count deviation is represented directly by slack variables in
the MILP objective. Other nonlinear topology statistics are scored only after
a chemically feasible solve. A result below the configured topology score is
probabilistically reprojected with a no-good cut; the best feasible result is
retained if the attempt budget is exhausted. Thus topology is a soft
preference, never a hard validity cap.

The highest-probability assignment is accepted without modification only when
it is chemically feasible and passes that probabilistic topology check.
Otherwise a sparse candidate MILP is attempted, followed by an expanded
fallback. For at most 24 atoms the fallback includes every atom state and every
atom pair. Train local-support membership remains an evaluation metric rather
than a generation filter.

## Topology and metrics

The former weighted-walk four-cycle expression is replaced by the exact
independent-edge expectation for simple triangles and quadrilaterals. Cumulene
probability is the exact Poisson-binomial probability of at least two double
bonds at an atom. Cycle rank, soft cyclic-core size and bridgehead probability
are now derived from the predicted adjacency itself; the detached graph-level
topology head has been removed. Bridgeheads are supervised against RDKit
`CalcNumBridgeheadAtoms`. Pointwise losses plus per-heavy-atom-count first,
second and soft-histogram Wasserstein losses match the train conditional
cycle-rank and ring-system-size distributions.

Three- and four-membered cycle supervision has a stronger, log-compressed
excess penalty so dense early predictions remain finite. No 3/4-ring,
bridgehead or ring-system statistic is used as a hard rejection rule.

Condition dropout remains molecule-wise classifier-free-guidance dropout.
Separate ordinary dropout regularizes context/time representations, every
node and edge residual block, prediction heads, the coordinate head and the
count MLP. It never removes a whole atom or molecular edge from the graph.

Generation reports separate columns and aggregate rates for:

1. raw RDKit validity;
2. raw joint aromatic-role validity;
3. final projection validity;
4. train-only support membership;
5. empirical train topology score;
6. chemically-clean topology warnings;
7. geometry of the coordinates generated by diffusion;
8. independently re-embedded ETKDG/force-field geometry.

Generated-coordinate evaluation measures train-referenced bond-length z-score,
bond outliers, nonlocal steric clashes, and optional MMFF/UFF relaxation from
the generated coordinates. It is not replaced by an ETKDG conformer.

## Split isolation and condition fidelity

The atom-state key vocabulary, local chemistry support, topology distribution,
bond-length reference and condition surrogate are fit on train only.
Validation and test are never added to support. The current train-derived state
keys nevertheless encode all held-out records.

Checkpoint ranking first maximizes the Wilson 95% lower bound of overall
chemical-clean validity, then overall chemical-clean rate, projection validity,
raw joint validity and mean topology-prior score. The selected artifact is
`best_chemical_clean.pt`; chemical-clean validity is therefore part of model
selection rather than a report-only diagnostic.

The checkpoint evaluator uses a structure-dependent S1/T1 surrogate: Morgan
radius-2 fingerprint plus molecular descriptors, standardized on train, then a
two-target ridge fit to database S1/T1. Its held-out validation performance is
stored in metadata. On this small dataset it is diagnostic, not an electronic
structure replacement:

- S1 MAE: 0.5990 eV, R2: 0.2849
- T1 MAE: 0.5333 eV, R2: 0.3818

For publishable condition fidelity, generated candidates should still be
re-evaluated with the existing XTB/STDA pipeline. The surrogate makes
condition response visible at every checkpoint without conflating it with
denoising loss.

## Artifact integrity

metadata.json contains:

- SHA-256 over manifest.json, train.pt, val.pt, and test.pt;
- a canonical SHA-256 over the complete metadata payload;
- SHA-256 for the five v7 model/chemistry/sampler/trainer source files;
- model type/configuration, exact atom-state vocabulary and marginals;
- train-only chemistry/geometry references;
- condition-surrogate coefficients and held-out metrics.

Sampling and resume fail closed if the external metadata, embedded checkpoint
metadata, checkpoint hash, or current DB bytes differ.

## Validation gate

Run the absolute-environment Python executable with validate_joint_kekule_v7.py.
The current report is validation/v7_validation_report.json. The gate passes:

- joint-edge encode/decode including CECPAD aromatic triples;
- RDKit identity for all 1,581/1,581 database molecules;
- train-only codec coverage of validation/test;
- joint MILP repair of a disconnected argmax;
- support/validity separation on 48 held-out out-of-support molecules;
- exact soft four-cycle counterexample (0.5^4 = 0.0625);
- generated-coordinate distortion detection;
- padding, permutation and O(3) checks;
- finite loss and gradients;
- one and only one projection call after reverse diffusion;
- metadata/checkpoint/DB hash mismatch rejection;
- structure-dependent S1/T1 surrogate evaluation.

## Reference alignment

- Austin et al., Structured Denoising Diffusion Models in Discrete
  State-Spaces (NeurIPS 2021): exact categorical posterior and combined
  x0-cross-entropy/VLB objective.
  https://arxiv.org/abs/2107.03006
- Vignac et al., DiGress (ICLR 2023): marginal-preserving categorical node
  and edge corruption, permutation-equivariant graph denoising, graph-level
  conditioning.
  https://arxiv.org/abs/2209.14734
- Vignac et al., MiDi (2023): joint molecular graph and Cartesian-coordinate
  diffusion rather than inferring bonds only after coordinate generation.
  https://arxiv.org/abs/2302.09048
- Hoogeboom et al., Equivariant Diffusion for Molecule Generation in 3D
  (ICML 2022): centered coordinate diffusion and E(3)-equivariant score.
  https://proceedings.mlr.press/v162/hoogeboom22a.html

V7 follows these mathematical interfaces, but its final chemistry MILP,
heavy-atom residual-hydrogen state and train-only HP1KG S1/T1 surrogate are
project-specific additions.
